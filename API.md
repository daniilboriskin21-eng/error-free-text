# Error Free Text — контракт REST API

Приложение принимает текст, сохраняет задачу и исправляет опечатки
в фоновом режиме. Пользователь получает идентификатор задачи,
по которому затем запрашивает состояние и результат.

При локальном запуске базовый адрес: http://localhost:8080.

Тела запросов и ответов используют JSON.
Для POST-запроса требуется заголовок Content-Type: application/json.

## Создание задачи

POST /tasks

### Тело запроса

```json
{
  "text": "Превет, мир!",
  "language": "RU"
}
```

### Валидация

- Поле language обязательно. Допустимые значения: RU и EN.
- Поле text обязательно и не может быть null.
- Текст должен содержать минимум 3 символа.
- Текст должен содержать хотя бы одну букву.
- Текст длиннее 10 000 символов допускается.
- Пробелы и переносы строк исходного текста сохраняются.

### Успешный ответ

HTTP 201 Created.

Заголовок Location содержит путь к созданной задаче:
/tasks/44bd78dc-d08c-41c6-b87d-fb82046bd470

```json
{
  "id": "44bd78dc-d08c-41c6-b87d-fb82046bd470"
}
```

Ответ означает, что задача сохранена в БД со статусом NEW.
Корректировка текста выполняется позже.

## Получение состояния задачи

GET /tasks/{id}

Параметр id — идентификатор задачи в формате UUID.

Для существующей задачи возвращается HTTP 200 OK.
Состав ответа зависит от статуса задачи.

### Задача ожидает обработки

```json
{
  "status": "NEW"
}
```

### Задача обрабатывается

```json
{
  "status": "PROCESSING"
}
```

### Задача успешно завершена

```json
{
  "status": "COMPLETED",
  "correctedText": "Привет, мир!"
}
```

### Обработка завершилась ошибкой

```json
{
  "status": "ERROR",
  "errorMessage": "Сервис проверки текста недоступен"
}
```

HTTP 200 означает успешное получение состояния задачи.
Статус ERROR описывает ошибку фоновой обработки.

Поля, не относящиеся к текущему статусу, отсутствуют в ответе.

## Ошибки обработки HTTP-запросов

Ошибки возвращаются в едином формате:

```json
{
  "errorMessage": "Task with id: 44bd78dc-d08c-41c6-b87d-fb82046bd470 not found",
  "errorCode": 40401,
  "timestamp": "2026-09-30T12:00:00+03:00",
  "path": "/tasks/44bd78dc-d08c-41c6-b87d-fb82046bd470"
}
```

Поля ответа:

- errorMessage — понятное описание ошибки.
- errorCode — внутренний числовой код ошибки приложения.
- timestamp — время возникновения ошибки в формате ISO 8601
  с указанием смещения часового пояса.
- path — путь запроса, при обработке которого возникла ошибка.

| HTTP-статус | errorCode | Причина |
|---|---|---|
| 400 Bad Request | 40001 | Невалидные поля text или language |
| 400 Bad Request | 40002 | Некорректный JSON или тип значения |
| 400 Bad Request | 40003 | Некорректный формат UUID |
| 404 Not Found | 40401 | Задача не найдена |
| 405 Method Not Allowed | 40501 | HTTP-метод не поддерживается для этого endpoint |
| 415 Unsupported Media Type | 41501 | Неподдреживаемый Content-Type |
| 500 Internal Server Error | 50001 | Непредвиденная ошибка сервера |

Внутренние технические подробности и stack trace не возвращаются клиенту.
